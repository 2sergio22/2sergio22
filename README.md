# 💫 About Me:
👋 ¡Hola! Soy Sergio, estudiante de Desarrollo de Aplicaciones Web (DAW) y un apasionado de la tecnología y la programación. Me gusta aprender cosas nuevas, descubrir cómo funcionan las aplicaciones y poner en práctica mis conocimientos creando mis propios proyectos.
